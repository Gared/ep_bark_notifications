# Instructions

This plugin allows users to subscribe to pads and receive Bark reminders when pads are opened or closed. This plugin is still in early stage.

# Installation

Copy/Edit the below to your settings.json

```
 "ep_bark_notifications" : {
    "device_key": "******", //the default server key for Bark
    "sound": "calypso",  //ringtone reminder
    "padIdArray": ["love", "heart"]  //padIdArray
  }
```
